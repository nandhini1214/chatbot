# 🌸 Period Tracker Application

A comprehensive period tracking application built with Streamlit that helps you monitor your menstrual cycle, log symptoms, and predict future periods.

## Features

- **📊 Dashboard**: Overview of your cycle statistics and recent data
- **📅 Period Logging**: Easy-to-use forms to log your periods with flow intensity and notes
- **😷 Symptom Tracking**: Track various symptoms with severity levels
- **📈 Analytics**: Visualize cycle trends and symptom patterns
- **🔮 Predictions**: Get predictions for your next period and fertility window
- **📅 Calendar View**: Visual calendar showing predicted periods and fertile days

## Getting Started

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run run_streamlit.py
```

Or alternatively:
```bash
streamlit run main.py
```

## Data Storage

The application uses SQLite database to store your data locally and securely. All your personal information stays on your device.

## Privacy

Your period tracking data is stored locally on your device and is not shared with any external services.
